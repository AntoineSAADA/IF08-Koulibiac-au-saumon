# IF08-Koulibiac

Bienvenue sur le dépôt du projet **Koulibiac**, réalisé dans le cadre de l'UE IF08 à l'UTT.
Ce projet consiste en la création d'un site web dédié à la présentation d'une recette de cuisine.

## Description du Projet
Le site web "Koulibiac" permet de présenter une recette de cuisine de manière structurée, incluant la liste des ingrédients, les étapes de préparation détaillées et une évaluation nutritionnelle (Nutri-Score).
